# Web Development Foundations & System Design

A practical learning journey through web development fundamentals, API integration, and system design.

## About This Repository

This repository contains my daily assignments, practical exercises, and system design projects as I strengthen my web development and system design skills.

## Learning Journey

| Day | Focus |
|---|---|
| Day 1 | HTML foundations and page structure |
| Day 2 | Multiple pages and CSS styling |
| Day 3 | JavaScript fundamentals |
| Day 4 | Interactive QuickNotes application |
| Day 5 | API integration and asynchronous JavaScript |
| Day 6 | SQL and database fundamentals |
| Day 7 | SnapShare system design and scaling |
| Day 8 | TicketHub event ticketing system design |

## Projects

### QuickNotes

A notes application featuring categories, search, character validation, timestamps, and browser local storage.

### QuickNotes System Design

An exploration of API integration, data models, architecture, and system design trade-offs.

### SnapShare

A system design exercise focused on application scaling and architecture.

### TicketHub

An event ticketing system design covering requirements, REST API endpoints, data modelling, architecture, and prevention of double bookings.

## Technologies and Concepts

- HTML and CSS
- JavaScript
- REST APIs
- Git and GitHub
- SQL and databases
- System design and architecture
- Caching, scalability, and reliability

## Getting Started

Clone the repository using these commands:

    git clone https://github.com/Markle-art/web-foundations-days.git
    cd web-foundations-days

Explore the folders for each day's exercises and assignments.

## Learning Philosophy

Build the fundamentals, practise consistently, understand technical trade-offs, and document the reasoning behind design decisions.
